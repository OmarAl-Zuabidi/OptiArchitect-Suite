# Contributing to OptiArchitect

First off, thank you for considering contributing to **OptiArchitect**! It is contributions like yours that make open-source software a fantastic tool for the academic and educational community.

---

## Code of Conduct

By participating in this project, you are expected to maintain a respectful, inclusive, and welcoming environment for all contributors and users.

---

## How Can I Contribute?

### 1. Reporting Bugs
If you find a bug or incorrect output in any of the algorithms:
* Open an Issue on GitHub.
* Describe the problem clearly, including the input data and expected vs. actual output.
* Specify the environment (Python version, OS, running via CLI or Streamlit).

### 2. Suggesting Enhancements
We welcome ideas for new features, additional Operations Research algorithms, or interface improvements:
* Open a Feature Request Issue.
* Explain why this enhancement would be useful to students or researchers.

### 3. Submitting Pull Requests (PRs)
If you want to contribute code, fix a bug, or add a feature:

   git checkout -b feature/your-feature-name
